## 🚀 Flutter AI Code Interpreter App

This repository now also includes a complete **Flutter mobile application** that interprets and executes code in multiple programming languages using cloud-based AI training!

### Features

- Support for **11 programming languages**: Python, JavaScript, Java, C++, Go, Rust, TypeScript, PHP, Ruby, Swift, Kotlin
- Clean, modern Material Design 3 UI
- Real-time code execution (demo mode included)
- Sample code for all languages
- Cross-platform: Android & iOS

### Get Started

```bash
# Install dependencies
flutter pub get

# Run the app
flutter run
```
